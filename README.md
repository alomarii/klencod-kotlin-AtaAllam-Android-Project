# أتعلم وأستمتع - مشروع أندرويد

## طريقة الاستخدام
1. ثبّت Android Studio (إصدار Koala 2024.1 أو أحدث).
2. افتح Android Studio ← Open ← اختر مجلد المشروع AtaAllam.
3. انتظر انتهاء Gradle Sync (يحتاج إنترنت أول مرة).
4. للتجربة: اضغط Run ▶ على هاتف أو محاكي.
5. لإنشاء ملف APK: Build ← Build Bundle(s) / APK(s) ← Build APK(s).
   (للنشر على Google Play: Build ← Generate Signed Bundle / APK.)

## ملاحظات
- أقل إصدار مدعوم: Android 8.0 (API 26).
- ملف الواجهة: app/src/main/assets/index.html
- النطق الصوتي يعمل عبر محرك Android TextToSpeech؛ إن لم تسمع صوتًا ثبّت اللغة العربية من إعدادات الجهاز > تحويل النص إلى كلام.
- الرمز الافتراضي للوالدين: 1234 (يمكن تغييره من لوحة الوالدين).
